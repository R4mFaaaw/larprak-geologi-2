Folder Musik GeoStruktur Studio
==============================

1. Kamu bisa menambahkan file musik favoritmu (.mp3, .wav, .ogg, .m4a) ke dalam folder ini.
2. Jika menjalankan website lewat `start_website.bat` atau `python server.py`,
   semua lagu baru di folder ini otomatis muncul di Menu Musik!
3. Jika membuka `index.html` langsung di browser, kamu juga bisa klik tombol
   '+ Tambah Lagu dari Laptop' di dalam Menu Musik untuk memutar lagu apapun secara instan.
